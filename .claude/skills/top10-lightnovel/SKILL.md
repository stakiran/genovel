# top10-lightnovel

## 目的

ある年のライトノベル年間売上トップ10を、各作品の固有性を残しつつ統一フォーマットで wiki に蓄積する。

## 全体フロー

### フェーズA: ランキング確定（一度きり）
- A-1: **ランキング取得**: 指定年の年間売上トップ10を WebSearch で取得。2〜3箇所調べて一致したら確定。深堀りは不要
- A-2: **入口ファイルの作成**: `wiki/<year>.scb` に順位/作品名/著者/レーベルを scb 記法で書く。作品名はリンク化 `[作品名]` する

→ ここまで完了して初めてフェーズBに進む。フェーズB前にランキングが10件揃っていなければ、欠けを埋めてから進む

### フェーズB: 各作品の内容埋め（1作品ずつ完結させる）
ランキング上位から順に**1作品ずつ完結させてから次の作品に進む**。並行で複数作品を進めない。

各作品について以下のサイクルを回す:

- B-1: **既存チェック**: `wiki/<作品名>.scb` がすでに存在するならスキップして次の作品へ進む（複数年ランクイン作品はすでに存在する内容を尊重）
- B-2: **情報収集**: その作品について WebSearch で必要な情報を集める
- B-3: **ファイル作成**: `wiki/<作品名>.scb` を後述の構成で一気に書き切る
- B-4: **次の作品へ**: 完了したら次の作品に進む。前の作品に戻って加筆しない

## 各作品ファイルの構成

1. **メタ情報** (タイトル行 + 1段下げ)
   - 入口ファイルに書いた情報の再載で良い
2. **ジャンルと舞台設定と世界観**
   - ジャンルタグ (異世界/学園/バトル/ラブコメ/SF…)
   - 舞台 (時代/場所)
   - 世界観 (固有名詞・システムを明示)
3. **文体**
   - **広く知られた短い決め台詞のみを引用** (1作品あたり数行まで)
   - 確信度が低いものは出さない
   - **自分の言葉での文体描写・パスティーシュは禁止**。引用のみ
4. **あらすじ**
   - 対象年時点の刊行範囲ぶんを順を追って記述
   - 各編 (アーク) の起点と決着を押さえる
5. **主要キャラクター**
   - **必ず10人**。主人公とメインヒロインとサブヒロインは必ず含める
   - 各キャラに以下を記述:
     - 立ち位置 (主人公/メインヒロイン/サブヒロイン/ボス/仲間 など)
     - 容姿
     - 設定と属性
     - 主人公との関係 (登場初期 / 起承転結後 の2時点)
     - 代表的なセリフ
6. **男性読者のどんな性癖に刺さったか**
   - 一般論として箇条書き
7. **男性読者にどんなカタルシスをもたらしたか**
   - 一般論として箇条書き
