# top10-lightnovel

## 目的

ある年のライトノベル年間売上トップ10を、各作品の固有性を残しつつ統一フォーマットで wiki に蓄積する。

## 全体フロー

1. **ランキング取得**: 指定年の年間売上トップ10を WebSearch で取得 (オリコン年間"本"ランキング 文庫シリーズ別が一次資料)
2. **入口ファイルの作成**: `wiki/<year>.scb` に順位/作品名/売上部数/著者/レーベル/出典を scb 記法で書く。作品名はリンク化 `[作品名]` する
3. **各作品ファイルの作成**: `wiki/<year>.scb` からリンクされた表記そのままのファイル名で `wiki/<作品名>.scb` を1作品=1ファイルで作成

## 入口ファイル (`wiki/<year>.scb`)

- scb 記法で書く (markdown 版は作らない)
- トップ10の各行に: 順位、`[作品名]` (リンク化)、売上部数、`[著者]`、`[レーベル]`

## 各作品ファイル (`wiki/<作品名>.scb`)

ファイル名は入口ファイルのリンク表記と完全一致させる (リンク先がないと scb のネットワークが壊れる)。`.claude/rules/scb_file.md` のファイル名サニタイズルールを適用。

### 必須セクション (この順序で記述)

1. **メタ情報** (タイトル行 + 1段下げ)
   - ランキング情報へのリンク・順位・売上部数
   - 著者、イラストレーター、レーベル、刊行開始
   - **対象年時点の刊行範囲** (例「2012年時点で1〜10巻」)。シリーズ全体ではなく対象年当時の刊行ぶんに範囲を限定する
   - 各巻のエピソード/編区分

2. **ジャンルと舞台設定と世界観**
   - ジャンルタグ (異世界/学園/バトル/ラブコメ/SF…)
   - 舞台 (時代/場所)
   - 世界観 (固有名詞・システムを明示。RAGのヒット率に直結する重要セクション)

3. **文体**
   - **広く知られた短い決め台詞のみを引用** (1作品あたり数行まで)
   - 確信度が低いものは出さない (記憶ベース誤記=捏造になるため)
   - **自分の言葉での文体描写・パスティーシュは禁止**。引用のみ
   - 確信のあるセリフがない場合はこのセクションは省略可

4. **あらすじ**
   - 対象年時点の刊行範囲ぶんを順を追って記述
   - 各編 (アーク) の起点と決着を押さえる

5. **主要キャラクター**
   - **必ず10人**。以下を必須で含む:
     - 主人公
     - メインヒロイン
     - サブヒロイン (各編のヒロイン枠を含む)
     - ボス (各編のボスを含む)
   - 各キャラに以下を記述:
     - 立ち位置 (主人公/メインヒロイン/サブヒロイン/ボス/仲間 など)
     - 容姿
     - 設定と属性
     - 主人公との関係 (登場初期 / 起承転結後 の2時点)
     - 代表的なセリフ (確信度の低いものは「(なし)」と明記)
   - キャラ名はリンク化 `[キャラ名]`

6. **男性読者のどんな性癖に刺さったか**
   - 一般論として箇条書き (個人の主観ではなく、当時のオタク言説・レビューで広く語られた文脈)

7. **男性読者にどんなカタルシスをもたらしたか**
   - 一般論として箇条書き
   - 「主人公にとっての勝利の瞬間」「読者の自己投影が成就する場面」を特定する

### scb 記法ルール (再掲)

- 1-space 1-indent の箇条書き
- 空行で区切られた塊が構造を示す
- リンクは `[ページ名]`、リンク先のファイル名はサニタイズ済みの `ページ名.scb`
- コードブロックは `code:xxx` 〜 `:c`
- 詳細は `.claude/rules/scb_file.md` を参照

### リンク化対象

- 作品名、著者名、イラストレーター名、レーベル名
- キャラ名 (本名・通称ともに)
- 関連する世界観固有名詞 (任意。RAGで横断検索したい語に絞る)

## 引用ポリシー (重要)

- **OK**: 1〜2行の決め台詞、ミーム化したキャッチコピー
- **NG**: 地の文を段落単位で再現、章冒頭の丸写し、戦闘描写の連続段落
- **NG**: 自分の言葉で作品の文体を真似て書く (パスティーシュ)
- **NG**: 記憶があやふやな「忠実引用」(誤記=捏造)
- 確信が持てないセリフは出さない。空欄(なし)で良い

## 構造スケルトン (インデントの参考のみ。文言・粒度は引きずらないこと)

```
[作品名]
 [<year>ライトノベル売上ランキングトップ<順位>] <部数>
 著者 [...]
 イラスト [...]
 レーベル [...]
 刊行 yyyy/mm〜
 <year>年時点の刊行範囲 ...

ジャンルと舞台設定と世界観
 ジャンル ...
 舞台 ...
 世界観
  ...

文体
 (確信度の高い短い決め台詞のみ。なければセクションごと省略)

あらすじ
 ...

主要キャラクター
 [キャラ名A]
  立ち位置 ...
  容姿 ...
  設定と属性 ...
  主人公との関係
   登場初期 ...
   起承転結後 ...
  代表的なセリフ ...

```

スケルトンは**インデント階層と項目順を示すだけ**。各作品の内容・観点・語り口は作品固有のものを優先し、他作品の書き方に揃えにいかないこと。

## 作業の進め方
処理時間を抑えるために、また進捗感を見せるために、一つずつこなしていこう。

- 1: まずトップ10を `<year>.scb` に記述しきる
- 2: その後で、トップ10として記載した各作品ファイルをつくる
    - このとき、まず作品ごとの必要な情報を取得しきったあと、最後にファイルに書いていくのがいいだろう

## すでにファイル名が存在するとき
複数年にランクインした作品がある場合、ファイル名がすでに存在していることがある。その場合は何もせずスルーして良い（すでに存在する内容を尊重）。
