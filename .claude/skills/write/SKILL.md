# write

## 目的
`wiki/<title>.scb` に書かれた小説設定を読み込み、そこに記述された指示・ルール・フォーマット・キャラ設定・カタルシス等に従って小説本編を一冊分書き上げる。

## 使い方
ユーザーは対象 scb ファイルを引数や @ 参照で渡す。例:

- `/write wiki/<title>.scb`

ただし呼び出し時に追加指示を与えることはある。例:

- `/write wiki/<title>.scb 一章分を書いてみて`
- `/write wiki/<title>.scb 一章分を3パターン書いてみて`
- `/write wiki/<title>.scb 1パターンだけ残した。続きを書いて`

## 手順
1. **読み込み**: 指定された .scb ファイルを Read で全文読む
2. **遵守事項の把握**: ファイル内に書かれている以下をすべて拾う
3. **執筆**: 上記すべてを反映した本編を Write で出力先に書き出す。途中で省略せず、指定された分量を満たすこと
